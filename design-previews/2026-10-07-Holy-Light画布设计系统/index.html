A · 暗房仪器 — 像一台徕卡机身 / 调色台

字体
中文系统栈；参数、尺寸、seed 走等宽
色彩
纯黑画布 #000 + 面板链 #141414 / #1c1c1c / #242424；单一暖白强调 #f5f2ea
布局
左轨浮层 + 底栏浮层，画布无限延展
记忆点
一切数字都是等宽表格数字，纵向永远对齐
推荐理由
它是现有系统的进化不是推翻，改动可控；四级灰阶直接修掉对比度问题；暗底中性灰适合长时间盯屏
可混搭：要 B 的衬线标题、或 D 的节点类型配色

B · 制版台 — 像印刷打样稿 / 工程图纸

字体
衬线做标题（子集化）+ 等宽做参数，最接近「纸」
色彩
纸白 #f2efe9 + 墨黑 #1a1a18 + 朱砂 #c0392b
布局
左轨变成有编号的实体栏，1px 规则线切分
记忆点
卡片带 3px 硬偏移，像套印没对准
适合
想让产品「不像又一个 AI 工具」、且白天使用为主
可混搭：要 A 的暗底，但保留衬线标题与朱砂

C · 暗色控制台 — 像示波器 / 音频工作站

字体
全等宽，中文也走等宽 fallback
色彩
近黑带绿 #080b09 + 荧光青绿 #7dffb0，副色琥珀
布局
方角、1px 实描边、扫描线覆盖
记忆点
顶栏品牌名带闪烁光标
代价
中文在等宽 fallback 下字形会偏，长段落可读性最弱
可混搭：只要 C 的状态色（琥珀运行 / 青绿完成）

D · 玻璃工坊 — 像一间有天窗的工作室

字体
几何无衬线 + 中文系统栈
色彩
中调灰 #24252a；文本蓝 / 图像粉 / 视频绿 / 音频黄 / 超清紫
布局
大圆角 12 / 18 / 24，浮层走真玻璃
记忆点
节点类型各有颜色——一眼分清这条链上都是什么
代价
玻璃在 Electron 合成层上可能出横纹（本机已踩过一次）
可混搭：要 D 的类型配色，但回到 A 的纯黑与无玻璃
