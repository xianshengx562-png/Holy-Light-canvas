# AIFISHER-COMFYUI 画布输入

这个扩展提供一组「画布输入」节点。把工作流里想交给画布调整的输入接到它们上面，
AIFISHER 导入这个工作流时就直接生成对应的画布参数，不必再到参数配置页逐个勾选。

## 节点

| 节点 | 输出 | 用途 |
| --- | --- | --- |
| 画布文本输入 | STRING | 提示词、风格描述等文本 |
| 画布小数输入 | FLOAT | CFG、降噪强度等小数 |
| 画布整数输入 | INT | 步数、宽高等整数 |
| 画布种子输入 | INT | 种子，画布默认按随机处理 |
| 画布开关输入 | BOOLEAN | 是非选项 |
| 画布图片输入 | IMAGE | 画布连进来的图片 |
| 画布蒙版输入 | MASK | 画布连进来的蒙版 |

每个节点除了被取的值，还有四个只给 AIFISHER 读的说明字段：

- **画布名称**：参数在画布上显示的名字。留空时用节点标题。
- **画布分组**：参数归到哪一组，默认「基础参数」。
- **画布顺序**：同组内从小到大排。
- **折进高级**：勾上后收进节点的「参数配置」，不占创作主界面。

图片输入另有「允许多张」，勾上后画布可以连多张图。

## 用法

1. 在 ComfyUI 里把原来的输入改接到对应的画布输入节点上。
2. 填好画布名称和分组。
3. 在 ComfyUI 里照常跑一遍，确认工作流本身没问题。
4. 把工作流导入 AIFISHER，参数会按这里写的名称和分组直接出现。

节点在 ComfyUI 里就是普通的取值节点，不依赖 AIFISHER 也能单独使用；
AIFISHER 只是多读了那几个说明字段。

## 安装

AIFISHER 画布用户在「设置 → 开源服务」里一键安装或更新；运行中的 ComfyUI 不会被
自动重启，不会中断队列任务。

其他启动器把完整的 `fisherai_canvas_inputs` 文件夹复制到
`ComfyUI/custom_nodes/fisherai_canvas_inputs`，再重启 ComfyUI。
