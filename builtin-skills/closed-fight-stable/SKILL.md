## 2. 结构与节奏（为什么这样切）

### 2.1 二十一拍分布

| 幕 | 拍数 | 单拍均长 | 作用 |
|---|---|---|---|
| 一幕 0-10s | 9 拍 | ≈1.1s | 密集快切，建立能力与压迫感 |
| 二幕 10-20s | 6 拍 | ≈1.7s | 放大爽感 → 打到最低点 → 反转 |
| 三幕 20-30s | 6 拍 | ≈1.7s | BOSS 战、终极一击、余韵定格 |

**越往后单拍越长**——动作规模变大需要呼吸。不要在第三幕塞一幕的密度。

| 2 | 1.0-2.0 | 借力腾空 | 13 | 14-15.5 | **重创跪地（最低点）** |

### 2.2 情绪曲线：三起两落

```
压制 → 受挫(3s) → 反杀 → 险境 → 升空留白(9s)
     → 全面压制(10-13s，爽点一)
     → 跪地重创(14s，最低点) → 连锁反转(17.5s，爽点二)
     → BOSS登场把爽感清零(18.5s) → 周旋爬坡 → 终极留白(24s)
     → 终极一击(26.5s，最高点) → 余韵 → 定格
```

这条曲线是 30 秒能"看得下去"的**唯一原因**。删掉 14s 的重创，全片就变成无聊的一路平推。

### 2.3 震动配额（严格执行，超标即无高潮）

| 等级 | 写法 | 次数 | 分配在哪 |
|---|---|---|---|
| 轻 | 「画面轻轻一震」 | ≈10 | 常规命中拍 |
| 中 | 「画面被冲击震得明显晃动」 | 4 | 3-4s、8-9s、14-15.5s、20-22s |
| 重 | 「画面剧烈晃动、白屏闪了三下、画面发晕」 | 3 | 10-11.5s、17-18.5s、26-28s |
| 零 | 完全不写震动 | 2 | 9-10s、18.5-20s（两个留白拍） |

**冷色调场景**把「白屏闪了三下」改写为「整个画面被{{主色}}的光闪白了三下」，观感更贴。

### 2.4 单拍写作公式

```
[时间码]：[起势/位移] + [发力部位] + [命中的具体部位] + [受击结果=规定的{{受击表现}}] + [衔接下一拍的惯性]；
运镜：[镜头做什么·大白话] + [焦点从X切到Y] + [震动等级] + [粒子反馈]
```

**语体铁律：动作写解剖学，运镜写大白话。**
- 动作 ✅「右手从箭壶抽箭搭弦拉满即放，箭矢命中持矛手腕」 ❌「发动攻击击中敌人」
- 运镜 ✅「镜头猛地甩向箭的方向，画面轻轻一震」 ❌「whip pan，camera shake，flash frame」

术语模型响应差，大白话响应好；反过来动作越具体越可控。**两者不要互换语体。**

## 4. 六条硬规则（改稿时别破坏）

1. **震动配额别超**：轻≈10 / 中4 / 重3 / 零震动留白2。多加一次「剧烈」，全片就没有高潮了。
2. **每拍必须有物理反馈**（震／尘／火星／碎屑／崩裂），少一个模型就出软绵绵的动作。
3. **命中必须写到具体部位**（手腕、喉甲、膝盖、肘节、眉心核心）。写"击中敌人"＝放弃控制权。
4. **运镜写大白话，动作写解剖学**，两者不要互换语体。
5. **三个连续性锚点不能删**：
   - 空间锚：`{{环境地标}}` 至少在 9s / 18.5s / 26s / 28s 出现四次
   - 时间锚：14s 的损伤累积描写 + 17s 的"先前破开的缺口"
   - 唯一性声明：**「定格全片只此一次」这句必须留**，否则模型会全片乱用冻结帧
6. **负面词里的禁血那句要写两遍**（重复＝加权，原版就是这么干的）。

## 5. 武器适配（换图最容易翻车的地方，按类型整段替换）

### ① 远程类（弓 / 枪械 / 飞刀 / 投射法术）
骨架即为此类，直接用。核心运镜＝**甩镜跟投射物、焦点手→飞行物、光轨织网、17s 连锁引爆**。

### ② 近战类（剑 / 刀 / 长枪 / 锤）
没有可跟的飞行物，改这五条：
- 甩镜触发源改成**挥击方向**：「镜头跟着刀锋划过的方向猛地甩一次，刀光在空中留下一道拖影」
- 焦点切换改成「焦点从握刀的手切到刀尖，再切到被劈开的甲片」
- 11.5-13s 光轨网 →「每一斩留下一道悬空不散的刀光，数十道刀光在空中交错成笼」
- 17s 连锁引爆 →「先前所有留在敌人身上的刀痕同时炸开」
- 26s 必杀 →「一记纵斩拉出撕裂天空的巨大刀光」

### ③ 法器 / 术式类（法轮 / 杖 / 符咒 / 剑诀 / 灵器）
- 贴地跟拍权重下调，改为**绕轴环绕**：「镜头绕着悬浮的法阵转一圈，符文一层层展开」
- 焦点链改成「浮空符文 → 术式核心 → 目标」
- 8-9s 起飞 →「法阵在脚下展开托举升空」
- 24-26s 蓄力 →「头顶巨型法阵层层叠加旋转」；26s 必杀 →「天降光柱／环形阵爆」
- 负面词手部改成「严控手印与结印手势精准」
- **注意**：纯法器版会牺牲速度感，建议保留一件可投射物（飞剑／剑气／符箭）来撑住甩镜逻辑

| **图生视频**（有参考图，首帧必须贴合） | 「0帧画面与参考图完全一致——{{原图构图描述}}；0.3秒{{破局事件：敌方发难／角色起手}}，随即{{第一击动作链}}」。张力照样在第一秒建立，且首帧不跑偏。 |

## 8. 常见翻车与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 出来是多机位剪辑 | 一镜到底约束不够强 | 负面词第一行前移到画质包正下方，且每一拍运镜都必须以「镜头跟着…」开头 |
| 动作软绵绵没力量 | 缺物理反馈 | 每拍补震动＋粒子（尘／火星／碎屑），一拍都不能漏 |
| 人脸糊 / 手糊 | 同拍镜头速度过高 | 保留运镜规格里「人物脸、手、{{武器握持部}}优先保持清晰」，并把该拍的镜头动作降一级 |
| 全片没高潮 | 震动配额超标 | 回到 2.3 节重新分配，把多余的「剧烈」降为「轻轻一震」 |
| 空间穿帮 / 场景漂移 | 环境地标出现次数不足 | `{{环境地标}}` 补足四次，并加负面词「严禁{{环境地标}}在同一镜头内位置漂移或凭空生长」 |
| 手指畸形 | 负面词太笼统 | 点名具体动作：「握弓、抽箭、拉弦精准」「并指剑诀、结印精准」 |
| 冷色调糊成一片死白 | 高光溢出 | 负面词加「严禁过曝糊成一片死白，严禁画面丢失黑位与层次」 |
| 巨型敌人躯干断裂错位 | 大体积生物形变失控 | 负面词加「严禁{{BOSS}}躯干出现断裂错位与鳞片/甲片漂浮」 |
