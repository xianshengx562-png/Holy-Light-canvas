# 详细成稿检查与改稿

## 硬性核对

先校准 [风格基准](style-contract.md)，再执行下表。默认高冲击稿须能在正文找到：持续推进的攻防回合、至少一处明确速度反差、关键重击的受力镜头与分级特效、尚有威胁时发挥作用的高潮、短而可读的结果。这些检查针对实际事件，不能只在开头堆关键词后声称达标。用户明确覆盖风格时按其要求检查。

| 项目 | 核对方法 | 不通过时怎么改 |
|---|---|---|
| 总时长 | 相加镜头时长，核对起止连续 | 调整时段或删去次要事件 |
| 输入分工 | 逐张比对身份、外形、质感用途 | 修正被错误继承的图像属性 |
| 武器状态 | 从首次出现一直追踪到结束 | 增加必要取放动作或简化换手 |
| 落地/升空 | 追踪脚下支撑、跃起与坠落 | 补起跳/着地或切明确全景 |
| 道具回收 | 检查离手、飞行、等待与接回 | 用符控等机制，或取消回收 |
| 技能来源 | 每招均可回答从哪里来 | 回到手势/器物/环境载体 |
| 升级衔接 | 后招利用什么前置状态 | 留符印、裂口、雷路或其他结果 |
| 胜负 | 结束时目标是否可见成立 | 给结果镜头留时间 |
| 动态风格 | 找到实际攻防推进、速度反差、关键命中的分级冲击与受力镜头 | 补事件内的动态表现，不只添加全局形容词 |
| 高潮用途 | 大招发动时尚有什么威胁，它解决了什么 | 将大招前移到有效对抗中，重排尾段 |
| 展示占时 | 标出无威胁的准备、摆拍和余韵各占多久 | 常规高冲击稿压缩无效等待，用户要求展示则保留 |
| 当前角色来源 | 检查武器、伤痕、能力和动作是否属于本次角色 | 删除无依据的旧案例遗留，按当前物件重写动作 |

## 五类常见改稿

### “不够酷”

先判断用户要展示什么能力。让核心能力成为主动动作，增加精准操作与大尺度结果的反差。保留对手有效反制，促成更高一级能力。

### “节奏再快，时长不变”

压缩重复铺垫与无效静止，把下一次威胁提前到上一镜结尾。复杂回合超载时删动作，而不是增加“瞬间”。高潮和结果仍有清楚读数。

### “上下镜头接不上”

对比出口与入口的位置、姿态、武器和轨迹。先修正实际动作；若只是视角跳变，选动作接切、敌方视角、遮挡或全景。不要让镜头移动掩盖角色瞬移。

### “要大场景技能”

扩大角色能力作用范围，同时让地形参与。加入形成、抵达、碰撞、地形结果，并保留本体与法相关系。近身段相应缩短以腾出时间。

### “换这张图”

记录换的是哪个主体或风格槽位。更新其外形及受结构影响的打法，不随意重置全部战场和其他角色。

## 有效检查示例

- 原始剑修样稿各镜标注相加为30.5秒，若目标30秒，应实际重排，而不是只改标题。
- 铜钱被击飞后十余秒才被接回，必须说明悬停/牵引；自由落体不会等待角色打完。
- 手持剑却写“左手拔剑”需要确认剑柄朝向与惯用手；选择一种贯穿全片。
- “弃手”语义不清，改为“左手松开长柄，右手保持握持，左掌拍剑侧”。
- 数百米法相出现后，贴身战机位不能一直看到完整全身；通过局部接触和全景交替解释尺度。
- 最后一镜包含神将出现、擒龙、摔龙、封印、收剑、拉远，事件过多，应把显形和擒拿前移。

## 输出检查记录

内部可记录“时长已核对；连续性已核对；参考图已核对；尚未实际生成视频”。仅在用户要求检查说明时展示。自查不等于独立审查，也不等于成片验证。
