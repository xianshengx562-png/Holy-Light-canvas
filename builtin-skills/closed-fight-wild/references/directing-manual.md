## 1. 输入与视觉分工

从当前对话整理：人物是谁、谁对谁、为何打、谁要达成什么、时长、画幅、图像用途、已确认技能、结局、声音要求。没有必要全部变成问卷；上下文已确定的直接使用。

为参考图建立映射：

| 图像用途 | 读取内容 | 输出转换 |
|---|---|---|
| 人物 | 脸、发式、年龄感、衣物结构、配饰、兵器 | 稳定外形锚点与出招载体 |
| 对手 | 体型、关节、攻击器官、武器 | 能成立的移动与攻击机制 |
| 环境 | 光线、气候、地形、植被、尺度 | 战场布局、运动阻碍与破坏反馈 |
| 质感 | 摄影/绘画、皮肤、材质、对比、饱和度 | 所有角色统一到同一成片语言 |
| 法相/天将 | 轮廓、头面、甲胄、持物、肢体 | 召唤后的稳定实体外形 |

图像特征按重要度取舍。主角冠冕、红伞、龙角这类决定识别和动作的特征要明确；无需把所有纹饰逐一枚举。图中没有展示的背面结构可以合理补全，但应与已见结构兼容。

多轮换图采用“替换指定槽位”：新龙图只替换龙，天将图只替换召唤物，道士照片仍定主角和山林质感。新图中的白底或灰底并不意味着战斗改到摄影棚。

输出前统一光源：阴天角色的甲片应反射灰天与树影；雷击后瞬时转白；赤金角色在冷林中仍保留服装本色，但不能把整片环境无故改成暖金神殿。

## 2. 角色打法与招式语法

每方建立六项：主要手段、攻击距离、发力方式、位移习惯、防御方式、受压后的升级。选择与外观和用户需求有关的项，不为每个角色发明庞大体系。

### 兵器与身体

- 剑：刺、挑、削、截、贴杆滑刃。靠路线、角度与步法造成威胁，重剑才适合反复抡砸。
- 禅杖/长杆：横架、下劈、杆尾回击、缩握、撑杆。杆长会影响树林中的回转，需要扫断障碍或改变握距。
- 伞：撑开卸击、伞缘旋削、收拢刺击、伞面遮挡。开合改变功能，伞骨弯曲回弹提供反馈。
- 徒手/掌法：拍、按、拧、托、拉、撞，交代接触部位与重心。巨掌同样需要肩肘和支撑腿参与。
- 符咒：取符、点燃、拍符、甩符、扣指、留印。每种手势对应可见后果。
- 妖龙：咬、爪击、甩尾、拧身、盘卷、吐息。胸颈和尾部跟随发力，不能同时向相反方向瞬间运动。

### 单次攻防句式

“甲借前一步的惯性，从某方向攻击乙的某部位；乙用某动作应对，造成某接触结果；双方因此进入某种新距离、姿态或危险。”

这只是内部组织句式，成稿要写成自然、具体的动作段落。

技能需有限制以产生选择：钵口吸摄让人难以正面逃离，因此绕钵侧；长杖砸空回收慢，因此贴杆进身；龙颈被控而尾部仍可反击，因此天将另一手要控制躯干。限制不一定靠讲解，用动作本身展示。

## 3. 酷感、主动性与攻防回合

用户说“不够酷”时先定位希望看的能力。若想看符咒、引雷、招神，单纯增加逃跑险情不能满足；需要让施法成为画面的主要事件。

可操作的酷感来源：

| 来源 | 具体实现 |
|---|---|
| 小动作驱动巨大结果 | 两指下压，山后的巨掌越过头顶按龙 |
| 极近危险中的精确操作 | 龙吻逼近时把一张符拍在鼻梁正中 |
| 攻防用途翻转 | 防御伞收拢为刺器，阻挡的巨掌变成踏脚点 |
| 多阶段能力同源 | 冠冕熔火沿服饰羽纹长成巨翼，再显化神凰 |
| 对手反制有效 | 符索确实被撕断、光障确实挡住首轮攻击 |
| 失败留下后手 | 破符留印，雷霆循印击中；破盾裂口被下一击扩大 |
| 悬殊尺度同框 | 粗布道士、巨龙头、山后天将同时可见 |
| 余势收尾 | 最后一击后碎石仍坠、龙仍喘息、衣摆仍回落 |

用“主动出招—反制—升级”组织一段，不必每次都让主角先败。强者可以连续压制，但对手的动作仍需促成变化。逆转可以靠机制、位置、时机，而不只有能量翻倍。

## 4. 时间与节奏

先确定能改变战局的高潮，再倒推交锋与升级，最后分配时间。30秒可采用短开场、两轮交锋、一个高潮、短收尾，也可把三种技能各占主要段落。不要把默认结构当严格配额。

动作负荷估计：

- 一个短镜适合一次起手及命中，或同一连续动作中的两三次简单碰撞。
- 对手反应、换手、重新找支点、变身与空间建立都是信息事件，各需读数。
- 长镜可以包含复杂动作，但摄像机应围绕同一明确目标，避免每半秒改变追踪对象。
- “高速”会压缩运动时间，不会自动消除理解人物是谁、攻击打在哪里的时间。

举例：2秒写“踩剑、起跳、剑绕身、接柄、接三道雷、翻身劈下”负荷很高。可以把御剑结束在上一镜，当前镜专注接雷，下一镜完成劈落；或直接删掉踩剑与绕剑，让道士站稳举剑。

节拍可采用“快、快、停、重”：两次轻招制造压力，极短接触停顿突出危险，重击改变局面。快慢不能全片同幅度重复。高潮前的静点可以短到0.1秒，但需要明确它停在哪里。

片尾至少留下能辨认结果的画面。30秒结束前才刚召唤出天将，就无法同时让观众看清镇压完成；应前移召唤或删减中段。

## 5. 连续性与镜头

### 五类状态

1. 空间：地标、朝向、高度、距离、屏幕运动方向。
2. 身体：脚是否落地、哪个部位在受力、当前惯性指向哪里。
3. 兵器：哪只手、是否出鞘、是否脱手、落在何处。
4. 技能：符是否贴住、绳索是否断裂、法相是否仍存在、效果有无残留。
5. 物件：铜钱等道具的轨迹、离手时间、遮挡期间是否仍能合理存在。

每次改稿从被改镜头向后检查，直到新的出口状态与原稿重新兼容。若把镜头6的剑从手里改为插地，后面举剑前必须交代拔剑。

### 切镜选择

动作接切适合命中，视线接切适合发现新威胁；敌方视角适合跨大距离定位；遮挡切镜适合快速移到动作另一侧；全景适合新空间和新巨物入场。

同轴跟拍只在目标与轨迹稳定时使用。穿铜钱方孔需要钱、镜头、远处目标短暂共线；铜钱没有孔时可翻面遮挡或圆形匹配切镜。不要为了“穿镜”改变物件结构。

越轴并非永远不可用：用可读连续环绕、正面中性镜头或全景交代再换侧。只写“镜头瞬间来到背后”会让左右关系跳变。

### 选择镜头的目的

| 镜头 | 用处 | 限制 |
|---|---|---|
| 手部微距 | 拍符、弹钱、拔剑与接触机制 | 之后要能重建人物位置 |
| 贴刃跟拍 | 保留挥击轨迹与速度 | 保留目标，避免只见光带 |
| 低位仰拍 | 人物压迫、落地、巨物遮天 | 借树、岩或人作为尺度 |
| 滑动变焦 | 压迫或新威胁显露 | 不承担复杂路径交代 |
| 急甩镜头 | 跟随反击、方向突变 | 落点应清楚，不连续模糊 |
| 急拉远 | 揭示法相与地形破坏 | 开始前明确镜头脱离谁 |
| 敌方主观 | 显示主角逼近、招神压迫 | 留可识别的身体边缘或视线依据 |

## 6. 符咒、雷法、法相与召神

### 符咒

符纸是实体：能折、燃、贴、撕。符印是法术：可以扩张、投影、连线、束缚。分别说明，避免纸刚被撕碎所有功能却毫无解释继续。

大符阵至少包含两个尺度：手指或纸上的笔画触发，地形或敌身上的对应笔画响应。符光主要贴附表面，才能看见束缚关系。

### 引雷

雷从云层或已确立能源抵达剑尖，持剑者承受负荷，再把雷送到目标。导雷方向应明确。若古剑既要载人又要举起接雷，安排离剑、握剑或落地，择一说明。

### 法相

先部分出现再揭全貌：巨掌挡住攻击后显全身，巨翼撑断锁链后长出神鸟头尾。出现后让它实际影响地形：压低树冠、推开云层、撞碎山壁、遮挡自然光。

本体同步法相应给出同步动作。巨大躯体的速度和动作幅度可不同，但主意图一致。法相受击后本体可以失衡或受压，帮助建立联系。

### 招神

按用户给定造型显神。凶相赤发重甲天将适合擒拿沉身；持器神将可用器物，不能因为“天将”就自动改成冠旒帝王或另加法器。

关系可以是召令后自主擒敌，也可以跟随道士手势；先在设定中选定。神明现身只是升级节点，最终还要完成抓握、镇压与敌方停止反抗。

## 7. 特效与物理反馈

设计三个层次：接触点局部形变；沿武器/身体传递的受力；周围环境响应。重击没有受击者位移，仅增加烟火，会显轻飘。

特效主色服务角色识别：如青绿剑气与暗金佛光，赤金火羽与黑金钵，冷白雷与朱砂符。材质可以相近但形态须不同：羽刃、梵文、绳索、雷枝各有轮廓。

默认按 [完整模板](prompt-template.md) 的三级碰撞预设落实冲击帧、负片、抽帧感与受力反馈；用户明确要求克制或取消时再调整。两人滑开且没有命中时使用惯性跟拍；真实命中的重击则要同时写出冲击节奏、身体/兵器受力和环境爆散，随后清楚显露结果。

身体受力也包括主角：接雷手臂下沉、锁龙被拖起、伞被撞凹。有效反馈会增强强者力量感，不等于主角狼狈失能。

## 8. 输出阶段与改稿

方案阶段写清主线、能力展示、时间骨架、关键构图和衔接依据。成稿阶段按模板写全局设定与逐镜段落。用户要求足够详细时，补足状态、动作与材质，不靠重复形容词扩写。

收到新反馈先确认改变的维度：角色、敌人、风格、技能、节奏、镜头、结果。以最新明确指令覆盖该维度，其他确认项继续保留。

最终检查使用 [revision-checklist.md](revision-checklist.md)。案例记录中的用户意见是已知反馈；案例正文的成功与否仍需实际生成检验，不能称已经验证出片。
