# 风格基准：继承这段对话的武戏质感

## 三层分工

1. 图像层：脸、服装、兵器、生物、场景材质、光线和主色。
2. 动作导演层：高密度连续攻防、追尾运镜、快慢反差、冲击分级、物理反馈、尺度揭示。这是本技能的默认表达。
3. 故事机制层：当前角色如何运用当前物件达成目标，敌人如何有效反制，大招如何解决尚存威胁。

三层分别填充，再合成提示词。不要用第一层的“柔光”替代第二层的“节奏”，也不要用旧案例第三层的道士技能替代新人物的战斗机制。

## 原始样稿需要继承的内容

首次以本技能写完整武戏时，读取 [用户原始写法节选](cases/00-original-style-excerpts.md)，以其文字密度、动态措辞、分级特效和空间尺度作为风格对照。案例01—04是经过整理的动作稿，用于机制与衔接；它们不能替代原文的表达强度标尺。

| 风格维度 | 成稿中的具体表现 |
|---|---|
| 速度 | 进攻后立即追击、拆招中改变路线，位移能跨越明确地标 |
| 力量 | 兵器压弯、身体下沉、鞋底犁地、甲板翻起，命中改变姿态 |
| 特效贴附 | 能量沿刃口、甲纹、书页或符印运行，发力时才离体冲出 |
| 运镜 | 贴着有效动作追拍，急甩落在反击方，急拉远展示真实范围 |
| 变速 | 接触前高速逼近，极短接触停顿，随后猛烈爆发；慢放用于点睛 |
| 冲击 | 轻击局部、重击受力与环境爆散、大招强烈冲击后可见结果 |
| 连贯 | 上一动作的方向、推力或余波成为下一动作起点，必要时直接切镜 |
| 升级 | 敌方反制迫使能力换用途，大招参与破防、镇压或反杀 |

## 真实失败样本：天书少年与机甲

用户反馈调用后的质感不同。其提供文本的可核查问题：

- 0—3秒主要为抚书读数，9个镜头大多机械分成3秒，最后一镜长6秒；整体缺少我们之前短促交锋的节拍。
- 敌人在18—21秒关节炸碎倒地；21—30秒才展开星阵再合书，最后大招没有对抗对象，后9秒变成展示。
- 多处“细碎光点、淡蓝光、微晃、半步”描写，没有对应的高速位移、重击接触和受力镜头。
- 标题写“剑尖雷脉”但角色只持书，正文突然出现“旧伤痕”，属于旧案例残留。
- 左手持书却又左手指天，下一镜仍持书，缺少手部状态交代。
- 原本“右臂为等离子刃”后来变成“武器脱手”，需要先交代刃臂断裂，或将初始设定改为手持武器。

这些证据能证明文本偏离风格；仅凭该输出不能确认调用时是否真正读了每个文件，也不能验证未提供参考图的光照是否被误读。

## 同一人物如何改回本风格

这是机制演示，不规定天书人物必须具备这些能力；按当前参考图和用户授权决定创作扩展。

开场让机甲刃锋已劈到书前：少年翻页展开晶面，斜卸刃锋，甲板被落空一击撕裂；他借冲击踏上掀起的板块，旋身扯动书页星丝，把机甲拉进反击路线。机甲启动推进器挣断星丝，沿断裂甲板追斩，威胁持续。

星阵在机甲仍能战斗时展开，必须改变战场：例如将残舰碎片锁定为阵点，封住冲刺路线；机甲破开一处阵点逼近，少年压下书页，阵纹将尚连通的阵点聚成一次有明确路径的终结攻击。最后1—2秒展示余波与结果。

### 局部写法对照

平缓写法：“星丝拉紧，机甲向前踉跄，少年抬臂。”

本风格写法：“机甲挥刃切开第一层星网，推进器喷焰追至面前！少年侧身翻页，三束星丝贴着刃臂绕入肘轴，右手骤然反扣；机甲的前冲惯性被扯成横甩，膝甲撞穿控制台，整片甲板向侧面掀起。镜头随刃臂急甩，在碰撞瞬间轴向猛沉，短促放射冲击帧后清晰露出仍在挣脱的机甲。”

区别来自反制、速度转向、有效命中和摄影反馈，不能只把原句加上“恐怖、极致、超高速”。

## 适用边界自检

- 输入“天书少年战机甲，沿用我们的30秒武戏”：应保留高冲击导演风格，重新设计书与机甲的机制。
- 输入“同人物，6秒安静的道具展示”：按展示需求交付，不硬塞敌人、对撞和终结技。
- 输入“纪实风格徒手搏斗，无法术和负片”：保留可读攻防与受力，按用户要求取消超自然和风格化冲击。
