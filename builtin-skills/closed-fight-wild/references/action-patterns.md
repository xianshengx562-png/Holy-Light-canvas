# 动作机制与衔接示例

这些是选择依据，不是固定招式库。根据人物与用户意图重新组合。

## 近身战：每次接触改变下一招

适用剑、杖、伞、徒手等近距离对抗。

例如：长杖下劈，持伞者倾斜伞面卸向侧方；杖刃砸地未能立即回收，持伞者借空隙近身；对手缩短握距，以杖尾顶开；伞面受击压弯，回弹带出双方距离。

区别于“挥剑、爆炸、再挥剑”，这里下一招由兵器位置和接触结果决定。对手的武器与双手必须保持可用状态：所谓“松手卸力”需要写清松哪只手、另一只手如何控制兵器。

## 巨物战：小角色借局部，大角色靠结构

以龙头、爪、角根、肩颈等局部作为人的可接触部位，再用全景揭示它们属于同一长躯。贴背镜头结束后，先交代角色怎么离开龙身，再切到地面。

长躯妖龙可以咬、抓、拧、缠、甩尾，但同一时间的动作应符合身体结构：一爪抓岩支撑转向时，这只爪不能同时攻击。大幅转身需要躯干弯曲和尾部跟随，不把它当瞬间掉头的光束。

巨物短时间位移很远时，用掠过树冠、踩塌崖壁、尾部延迟到达体现规模。保留可读速度，让观众看见“接近、接触、结果”。

## 法相与召唤：从载体到实体作用

“法相”可以是本体同步放大的能力，“招神”可以是响应召令而独立行动的盟友。选定一种关系并保持一致，避免时而同步、时而无故自主。

常见展开方式：

- 身体关联：衣甲纹理点亮，长出局部巨翼，轮廓延伸后显全身。
- 物件关联：符燃、剑导雷、灰烬升空，云后显眼与面，最后跨步入场。
- 环境关联：既有阵眼依次响应，地表纹路投进雾层，成形后压向目标。

显形同时可让敌人继续攻击，避免全员等技能读完。但给关键轮廓留出读数，不在两秒内同时完成召唤全身、跨山、擒拿、摔龙、封印和收尾。

## 让技能递进具有记忆

前一招即使失败也留下可用后果：破符留下印、破盾留下裂口、折断伞骨成为飞针、未散电流成为招神通路。后招应利用这些后果，而不是突然出现更亮的攻击。

胜利也需要可见条件。例如“降服”：先打断扑杀，再控制颈躯，再镇符锁住，最后呼吸仍在而爪与头放低。场面大小不替代结果交代。

## 三组衔接微例

### 动作接切

上一镜：符纸即将贴中龙吻。
下一镜：从同侧微距看纸面贴实、符纹展开、龙头向右偏转。
后镜：右侧山岩被龙头撞裂，龙爪借惯性横扫。

### 对手视角接切

上一镜：道士抬头望向低云。
下一镜：从妖龙俯视角度看道士位于浅水谷，画面边缘留龙须与下颌，吐息由前景冲向谷底。
后镜：地面斜侧机位，道士迎住同方向到来的吐息。

### 召唤跨尺度接切

上一镜：神符烧尽，灰烬沿雷线升入道士身后云层。
下一镜：直接切妖龙仰视，前景道士与后方云层同框，云内出现巨面。
后镜：侧全景交代天将、道士、龙三者位置，巨掌开始伸入扑杀路线。

## 30秒可行性演练

以下是设计阶段的时间骨架，用来判断动作负荷，不是要求每次使用的镜头表：

| 时段 | 核心事件 | 留给后续的状态 |
|---|---|---|
| 0—4秒 | 龙扑，道士侧移拍符封口 | 龙头偏转，道士获得出招间隙 |
| 4—8秒 | 甩符锁躯，龙拧身破索 | 龙升空，身上保留符印 |
| 8—12秒 | 龙息追击，道士切流御剑升空 | 道士接近低云，龙在下侧 |
| 12—16秒 | 道士接雷下劈，符印导雷击落龙 | 龙落谷，道士落高岩 |
| 16—20秒 | 插剑维持雷路，焚符招神 | 灰烬升云，龙恢复扑击能力 |
| 20—24秒 | 天将显形跨步，龙扑向道士 | 巨掌进入龙的攻击路线 |
| 24—28秒 | 扣颈控制身躯，沉身按落，镇符闭合 | 龙首受控，反抗减弱 |
| 28—30秒 | 龙低伏，道士收势，三者全景 | 清楚呈现降服完成 |

若增加复杂咬腕反制、空中翻转、换剑或第二轮擒拿，就需要删减其他事件或重分时长。不要原样加进去后仍宣称节奏可读。
